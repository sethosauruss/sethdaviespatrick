Cybersecurity Home Lab

In progress Rack rebuild planned for December

A self-built home lab simulating a small-scale enterprise IT environment, focused on infrastructure security, system administration and defensive cybersecurity.

View on GitHub

Running today

Surface Pro
A repurposed Microsoft Surface Pro with a broken screen, running Proxmox VE and Debian Linux. I've worked on SSH hardening, Fail2Ban intrusion prevention, Docker containers, firewall configuration and authentication log analysis. The architecture diagrams and config files are on GitHub.
Raspberry Pi 5
Runs CasaOS with Plex, Jellyfin, Tailscale and a remote monitoring app for my 3D printer, plus a Minecraft Bedrock server that is marked legacy and due for a rebuild.

The December rebuild

The plan is to move from two standalone machines to a rack with a dedicated firewall and network segmentation.

Hardware
Tecmojo 6U rack, TP-Link TL-SG108E managed switch, Dell OptiPlex 7040 Micro (i5-6500T, 16GB) as the lab host, a JetKVM for remote console access, and a second Raspberry Pi 5 so the K3s cluster has two nodes.
Firewall
pfSense. The box is still undecided. I'm tearing down a Fujitsu TeamPoS 7000 to check whether the mainboard detaches from the screen and how many network ports it has. If it works, it's a free firewall. If not, I'll buy a cheap secondhand micro PC.
Lab host
Proxmox running Kali Linux, Metasploitable2 and DVWA as practice targets, CALDERA and Atomic Red Team for adversary emulation, MITRE ATT&CK Navigator, Plex, and a SIEM.
K3s on the Pis
Pi-hole, Uptime Kuma, a Homepage or Homarr dashboard, Prometheus and Grafana, and the printer monitoring app, spread across both nodes.

Network segmentation

  • Lab: the Proxmox host and its practice targets, kept away from everything else.
  • Trusted: everyday devices.
  • IoT: smart and low-trust devices.

Order of work

  1. Fujitsu teardown: detach the screen, confirm the mainboard is modular, count the network ports.
  2. Decide on the SIEM: Wazuh, a self-built ELK stack, or both.
  3. Buy the second Raspberry Pi 5 and redistribute services across two K3s nodes.
  4. Design and print custom rack mounts for the firewall and the Dell host.
  5. Set up the Lab, Trusted and IoT VLANs once the firewall and switch are physically installed.

Open decisions

  • Wazuh or ELK. The Dell host has 16GB of RAM, and it also has to run Kali, the practice targets and the adversary emulation tools, so the SIEM's resource use matters.
  • Which firewall hardware. This depends on the Fujitsu teardown.

Cut from the build: UPS, patch panel, Tailscale, Jellyfin (Plex only) and the Minecraft Bedrock server.

Documentation

Everything is documented on GitHub. I plan to film the teardown, rack assembly and cabling and add short videos here once the build is done.
